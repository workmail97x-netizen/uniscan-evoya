UniScan Evoya

إعداد مرة واحدة للغربلة على الهاتف. بعدها افتح Evoya واضغط خانة الباركود فقط.
جارٍ معرفة نوع الجهاز…

إعداد Android

المسار المختبر عملياً: Microsoft Edge + Tampermonkey.
1
افتح Microsoft Edge
إذا مو مثبت، نزّله من Play Store.
2
ثبّت Tampermonkey
Edge → ⋯ → Extensions → Tampermonkey → Install.
3
ثبّت UniScan Evoya
Tampermonkey → Dashboard → Utilities → Import / Install from URL، ثم الصق الرابط الذي ينسخه الزر.
4
افتح Evoya
إذا ظهرت «UniScan جاهز ✓» وتم اختيار الأنبار تلقائياً، انتهى الإعداد.
تنزيل Microsoft Edge فتح نظام الغربلة

إعداد iPhone / iPad

المسار المعتمد: Safari + Userscripts.
أنت فاتح الصفحة من Microsoft Edge. على iPhone، Userscripts تعمل داخل Safari فقط. افتح نفس الرابط في Safari حتى يشتغل UniScan.
1
افتح هذه الصفحة في Safari
لا تكمل من Edge على iPhone.
2
ثبّت Userscripts
من App Store وافتحه مرة واحدة.
3
فعّل الإضافة في Safari
Settings → Apps → Safari → Extensions → Userscripts → On، واسمح لها بموقع Evoya.
4
ثبّت UniScan Evoya
اضغط «فتح ملف التثبيت»، ثم Extensions → Userscripts → Install.
تنزيل Userscripts فتح ملف تثبيت UniScan فتح نظام الغربلة

افتح الصفحة من الهاتف

هذه الصفحة مخصصة لـ Android وiPhone/iPad.
علامة النجاح: يتم تحديد «الانبار» تلقائياً وتظهر «UniScan جاهز ✓».
